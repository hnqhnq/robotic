## 四、Eval 结果汇总

### 4.1 成功率（主指标）

| 模型 | 成功数 | 成功率 | 论文/历史参考 | Δ（相对论文） |
|------|--------|--------|---------------|---------------|
| 官方 baseline（`ft-bitvla-libero-long`） | 418/500 | **83.6%** | 86.4%（λ=0） | **−2.8 pp** |
| TAR v4-tar01（λ=0.10，step 10000） | 442/500 | **88.4%** | 93.6%（λ=0.10） | **−5.2 pp** |
| **同环境 TAR − baseline** | +24 次 | **+4.8 pp** | +7.2 pp（历史） | **−2.4 pp** |

**解读**：

1. **方向正确**：在同一 OSMesa 环境下，TAR 仍显著高于官方 baseline（**+4.8 pp**）。
2. **绝对值未复现论文**：TAR 88.4% vs 93.6%；baseline 83.6% vs 86.4%。二者同向偏低，更符合 **eval 环境整体偏移 + 非同一训练 run**，而非单独 TAR checkpoint 加载错误。
3. **Smoothness 支持「TAR 训对了」**：λ=0.10 的 S1 / MaxJump 等与 Table IV λ=0.10 接近（见 §4.3）。

## 六、随机种子与可复现性说明

### 6.1 训练：**未设置全局 seed**

本次 v4-tar01 训练 **没有** 在 `scripts/train_tar.sh` 或 `vla-scripts/finetune_bitnet.py` 的 `FinetuneConfig` 中配置 `seed`，也 **未** 调用 `torch.manual_seed` / `numpy.random.seed` 等统一初始化。

因此，同配置 **重新训练** 会得到 **不同初始化与数据顺序**，最终 checkpoint 与 eval 成功率 **不保证** 与本次 88.4% 或 2026-05 报告的 93.6% 一致。

训练中仍存在的随机性来源包括：

| 来源 | 说明 |
|------|------|
| FSDP 多卡 | 4 卡分布式，采样与梯度同步顺序非严格确定性 |
| RLDS dataloader | `shuffle_buffer_size=100_000`，episode 顺序随机 |
| `image_aug=True` | 训练时随机图像增强 |
| CUDA / cuDNN | 未开启完整 deterministic 模式 |

**历史说明**：2026-05 论文主实验（93.6%）同样 **未在仓库中记录训练 seed**；该次权重已丢失，无法对照当时是否固定随机性。

### 6.2 Eval：**协议相对可复现**

`run_libero_eval_bitnet.py` 默认 **`seed=7`**（`set_seed_everywhere`，作用于 torch / numpy / random）；LIBERO 使用 **`initial_states_path=DEFAULT`**（固定初始状态）；环境侧 `env.seed(0)`（见 `libero_utils.py`）。

在 **同一 checkpoint、同一 MuJoCo/渲染环境** 下重复 eval，成功率应 **大致稳定**；本次 TAR 与 baseline 均完整跑满 500 episodes，无中途异常退出。

Eval 仍可能随 **MuJoCo 小版本、OSMesa/EGL、驱动** 略有波动（见 §3.2）。

### 6.3 第三方按论文/仓库复现时，应如何预期

| 复现目标 | 是否现实 | 说明 |
|----------|----------|------|
| **结论**：TAR 提升成功率、改善 smoothness、λ 增大趋势更好 | **较可能** | 代码、超参、数据与 eval 脚本已开源；本次同环境 **TAR +4.8 pp** 且 smoothness 与 Table IV 趋势一致 |
| **精确数字**：86.4% / 93.6% 及 Table 逐格完全一致 | **不保证** | 原 λ=0.10 checkpoint 不可用；训练无 seed；eval 环境与 2026-05 未完全对齐 |
| **合理区间** | 参考 | [REPRODUCE.md](REPRODUCE.md) 写 eval 约 **±1–3 pp**；**训练重跑** 带来的偏差可能 **更大**（本次 TAR 绝对值较历史低 5.2 pp，需同时看 baseline 是否同向偏低） |

**建议对外表述（复现者）**：

1. 固定 **eval 环境**（mujoco 2.3.7、robosuite 1.4.1、渲染后端、LIBERO task order）后，先跑 **官方 baseline**，再跑 **自训 TAR**，以 **同环境 Δ success** 为主指标。  
2. 不要仅与论文 **93.6%** 单点对比而忽略 baseline 偏移。  
3. 若投稿/附录要求严格可复现，应 **报告多次训练或多次 eval 的均值 ± 标准差**，或在后续版本增加 **`--seed` 训练选项** 并在复现实验中固定。

### 6.4 与本报告结论的关系

- 本次 **未完全复现 93.6%**，并不能单独归因于「没设 seed」；**环境差异、非同一权重** 同样重要。  
- 但 **未设 seed** 意味着：即使环境完全对齐，**重训也不应承诺** 复现到历史绝对成功率；能稳定复现的是 **方法有效性与相对提升**，而非 bit-exact 表格。

1. **附录 A 标签错误**：`TAR进度全流程梳理260909.md` 附录 A 标题为「λ=0.10」，但表中 10 项成功率均值为 **90.8%**，数值与 [20260418-实验报告.md](20260418-实验报告.md) 的 **v3 λ=0.05** 逐任务表一致，**不能**作为本次 λ=0.10 逐任务对照基准。

3. **REPRODUCE.md** 已说明 seed / FSDP 等与严格复现可能存在 **±1–3 pp**；本次 baseline **−2.8 pp** 在边界上，TAR **−5.2 pp** 超出该区间，需结合环境一并表述。

## 八、结论

| 维度 | 结论 |
|------|------|
| **训练复现** | λ=0.10 新训完成，step 10000 权重可用，loss 量级与历史报告一致 |
| **Eval 完整性** | TAR + baseline 各 **500/500** episodes，无进程异常退出 |
| **TAR 有效性（同环境）** | **88.4% vs 83.6%**，**+4.8 pp**；smoothness 相对 baseline 全面改善 |
| **论文主结果（绝对值）** | **未完全复现** 93.6% / +7.2 pp；更宜表述为「云环境 + 新权重下的相对提升」 |
| **代码/协议** | `eval_tar.sh` 与 `run_libero_eval_bitnet.py` 参数与论文 LIBERO-10 设定一致；Git 上 eval 主逻辑自 2026-09 入库后无功能性改动 |
| **训练 seed** | **未设置**；第三方重训不应预期复现 93.6% 等历史绝对值，宜以同环境 **TAR vs baseline** 为准 |

**推荐对外表述**：

> 在 2026-10 AutoDL 环境（OSMesa）下，重新训练的 BitVLA-TAR（λ=0.10）在 LIBERO-10 上达到 **88.4%**，较同环境官方 baseline **83.6%** 提升 **4.8 pp**；动作 smoothness 与论文趋势一致。绝对成功率低于 2026-05 记录的 93.6%，可能与 **非同一 checkpoint、MuJoCo/渲染环境差异** 有关。
