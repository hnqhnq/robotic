## 5. 插图恢复方案（方案 B，已采用）

原 LaTeX 插图文件丢失。曾尝试用 `generate_figures.py` 从实验报告数值重绘，但与定稿 PDF 视觉差异较大。

**当前采用方案 B：** 从定稿 PDF `doc/TAR-NingqiuHe.pdf` 按坐标裁剪 Fig.1–4，保证与投稿版本一致。

```bash
cd doc/paper
python scripts/extract_figures_from_pdf.py
latexmk -pdf main.tex
```

- Fig.2–4：与定稿完全一致（从 PDF 提取）
- Fig.1：右侧柱状图来自真实 eval；左侧轨迹图为论文定稿中的示意曲线（原 eval 轨迹已丢失，与定稿一致）

备选：`scripts/generate_figures.py` 仍可用于**仅更新数值**时重绘 Fig.2–4（需自行核对样式）。
