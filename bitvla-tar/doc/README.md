## 训练 / Eval 脚本

| 脚本 | 用途 |
|------|------|
| `scripts/train_tar.sh [λ] [tag]` | 通用 TAR 训练（v3/v4 共用） |
| `scripts/train_v4_ablation.sh` | v4 串联训练 λ=0.01 → 0.10 |
| `scripts/eval_tar.sh <ckpt> [label]` | 单模型 LIBERO-10 eval |
| `scripts/eval_v4_both.sh <ckpt_a> <ckpt_b>` | v4 串联 eval |
| `scripts/train_v3_tar.sh` | 兼容别名 → `train_tar.sh 0.05` |

`openvla-oft/ft_script/` 下有与实验报告同名的 wrapper（如 `ft_bitvla_libero_v4_tar001.sh`）。

## 格式说明

- **`.md`**：便于搜索、编辑和版本对比的 Markdown 版
- **`.pdf`**：原始汇报/导出版，保留排版与图表
- **`paper/`**：论文 LaTeX 源码，用于后续修改与投稿（定稿 PDF 见 `TAR-NingqiuHe.pdf`）

若只需快速查阅数据，优先看 `.md`；若需对照原始汇报材料，使用同名 `.pdf`。
