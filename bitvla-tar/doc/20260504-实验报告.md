# BitVLA-TAR v4 消融实验报告

**日期**：2026-05-04  
**汇报人**：何宁秋  
**模型基座**：BitVLA（bitvla-bf16）  
**任务集**：LIBERO-10（libero_10_no_noops）  
**实验目的**：对 TAR 正则化强度 `tar_lambda` 进行消融实验，测试 λ=0.01 和 λ=0.10 两个值，结合已有的 λ=0.0（baseline）和 λ=0.05（v3），构建完整的 4 点消融曲线，验证 TAR 强度与任务成功率、动作平滑度之间的关系。

---

## 一、实验背景

### 已有实验数据

v3 实验（详见 [20260418-实验报告.md](20260418-实验报告.md)）证明 `tar_lambda=0.05` 可将成功率从 86.4% 提升至 90.8%（+4.4%），同时全面改善动作平滑度。但仅有 2 个数据点无法回答：

1. **TAR 的效果是否随 λ 单调变化？** 还是存在最优点后性能下降？
2. **更小/更大的 λ 表现如何？** 论文需要消融曲线支撑超参数选择。

### 消融设计

选择 λ=0.01（弱正则）和 λ=0.10（强正则）两个消融点，与已有的 λ=0.0 和 λ=0.05 组成 4 点消融曲线：

| 组别 | tar_lambda | 说明 |
|------|------------|------|
| Baseline | 0.00 | 无 TAR，已有数据 |
| 消融 A | 0.01 | 弱正则，新增 |
| v3 | 0.05 | 中等正则，已有数据 |
| 消融 B | 0.10 | 强正则，新增 |

| 方案 | tar_lambda | 成功率 | InterBoundary | S1 | MaxJump |
|------|------------|--------|---------------|-----|---------|
| Baseline | 0.00 | 86.4% | 0.0477 | 0.0154 | 0.1613 |
| v3-TAR | 0.05 | 90.8% | 0.0451 | 0.0104 | 0.0794 |

## 七、结果分析

### 1. 成功率分析

成功率随 `tar_lambda` 呈现清晰的**单调递增**趋势：

- **λ=0.01**：仅施加微弱正则，成功率提升 2.6%，效果有限但方向正确
- **λ=0.05**：中等正则，成功率提升 4.4%，性价比较好
- **λ=0.10**：强正则，成功率提升 7.2%，是本次实验中的**最优值**

在测试的 λ 范围内**未观察到性能拐点**，即更强的正则并未导致欠拟合。这表明 TAR 的正则化效果在 λ ≤ 0.10 范围内是安全的。

### 2. 平滑度分析

**S1（chunk 内平滑度）**：

- 随 λ 增大持续降低：0.0154 → 0.0111 → 0.0104 → 0.0099（总降幅 **36%**）
- λ 从 0 到 0.01 的降幅最大（-28%），之后边际递减
- 即使少量 TAR 约束就能显著改善 chunk 内动作的连续性

**MaxJump（极端跳变）**：

- 从 0.1613 降至 0.0761（**↓53%**）
- λ=0.01 时已大幅下降至 0.0844（↓48%），后续提升有限
- TAR 在消除极端异常跳变方面效果尤为显著

**InterBoundary（chunk 边界跳变）**：

- λ=0.01 时达到最低值 **0.0421**（↓12%）
- λ=0.05 和 λ=0.10 时分别回升至 0.0451 和 0.0460
- 过强的 chunk 内约束可能使模型在 chunk 边界处产生略大的修正跳变
- **InterBoundary 的最优 λ（~0.01）与成功率的最优 λ（≥0.10）不一致**

**GripperSwitches（夹爪抖动）**：

- 随 λ 增大持续降低：0.572 → 0.497 → 0.439 → 0.435（**↓24%**）
- TAR 约束使夹爪动作更加稳定，减少了无意义的开合抖动

### 3. 成功率与平滑度的关系

| 指标 | 与成功率的相关性 | 最优 λ |
|------|------------------|--------|
| 成功率 | — | ≥0.10 |
| S1 | 负相关 ✅ | ≥0.10 |
| MaxJump | 负相关 ✅ | ≥0.10 |
| InterBoundary | 非单调 ⚠ | ~0.01 |
| GripperSwitches | 负相关 ✅ | ≥0.10 |

成功率与大部分平滑度指标高度一致：更平滑的动作序列 → 更高的成功率。唯一例外是 InterBoundary——chunk 内部的平滑度（S1、MaxJump）对任务完成的影响更大。

### 4. TAR 的作用机制

综合 4 个数据点，TAR 的作用可归纳为两个层面：

1. **直接效果——动作平滑化**：TAR 惩罚 chunk 首尾的高速度动作，使相邻 chunk 之间的过渡更加平滑。即使 λ=0.01 也能将 S1 降低 28%、MaxJump 降低 48%。
2. **间接效果——正则化提升泛化**：TAR 作为额外的训练约束，抑制了模型在训练集上的过拟合。这解释了为什么在 λ ≤ 0.10 范围内，更强的正则不仅没有降低成功率，反而持续提升。

### 5. 训练 loss 与 eval 性能的关系

| tar_lambda | 训练 loss | 成功率 |
|------------|-----------|--------|
| 0.01 | ~0.076 | 89.0% |
| 0.05 | 0.0746 | 90.8% |
| 0.10 | ~0.085 | 93.6% |

λ=0.10 的训练 loss 最高（~0.085），但 eval 成功率也最高（93.6%）。这进一步印证了 TAR 的正则化效果——较高的训练 loss 反映了更强的约束，而非更差的学习，模型在 eval 时反而泛化得更好。

---

## 八、结论

1. **TAR 正则化强度与成功率正相关**：在 λ ∈ [0, 0.10] 范围内，成功率随 `tar_lambda` 单调递增（86.4% → 89.0% → 90.8% → 93.6%），未出现过拟合拐点。
2. **λ=0.10 为当前最优值**：成功率 93.6%，较 baseline 提升 7.2 个百分点，较 v3（λ=0.05）提升 2.8 个百分点。
3. **平滑度指标全面改善**：S1 下降 36%，MaxJump 下降 53%，GripperSwitches 下降 24%。
4. **InterBoundary 存在非单调行为**：λ=0.01 时最低（0.0421），λ 增大后略回升，说明 chunk 内约束与 chunk 边界跳变之间存在 trade-off。
5. **TAR 兼具平滑化和正则化双重效果**：平滑化改善动作质量，正则化抑制过拟合提升泛化，两者共同驱动成功率提升。
6. **论文推荐**：λ ∈ [0.05, 0.10] 作为默认超参数区间。λ=0.05 是保守稳健的选择，λ=0.10 在当前实验中表现最优。

---

## 九、后续方向

- **更大 λ 值探索**：当前消融在 λ=0.10 处仍未达到拐点，可测试 λ=0.2、0.5 寻找性能饱和点或下降拐点
- **Per-task 分析**：对比 4 个 λ 值在每个任务上的成功率变化，识别哪些任务对 TAR 最敏感
- **更多 benchmark 验证**：在 LIBERO-Spatial、LIBERO-Object 等任务集上验证消融趋势的一致性
- **物理机器人部署**：将 λ=0.10 模型部署到真实硬件，验证平滑度改善的实际效果
